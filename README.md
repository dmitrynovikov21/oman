# ExpertOS - Oman Judicial Expert SaaS

## О проекте (About)
Этот репозиторий является центральным хранилищем проекта **ExpertOS** — системы автоматизации для судебных экспертов в Омане.
Здесь будет вестись вся разработка, храниться проектная документация, результаты анализа данных и прототипы.

## Структура репозитория (Structure)

### 📂 project_context/
Самая важная папка для понимания проекта. Содержит базу знаний, сформированную после реверс-инжиниринга исходных файлов клиента.
*   **GUIDE_RUSSIAN.md** — Полное руководство по проекту на русском языке. Объясняет бизнес-логику, расчеты (EOSB, переработки) и рабочий процесс без сложного кода.
*   **TECHNICAL_KNOWLEDGE_BASE_ENGLISH.md** — Техническая спецификация для разработчиков (на английском). Содержит псевдокод формул, правила OCR, схемы баз данных и маппинг переменных для шаблонов.
*   **CLIENT_QUESTIONS_RUSSIAN.md** — Список уточняющих вопросов для заказчика по бизнес-процессам и интеграции.

### 📂 ExperOS Files/
Исходные данные, предоставленные клиентом (для ознакомления и тестирования):
*   **Templates/** — Шаблоны Word для генерации отчетов.
*   **Sample Cases/** — Примеры реальных судебных дел (PDF, Excel, Word) для тестирования алгоритмов.
*   **Case Registrar/** — Реестр из 10,000+ дел.

### 📂 backend/ & frontend/ (In Development)
Папки для исходного кода новой разработки (Node.js/Python/React).

---

## Как использовать (Usage)
1.  **Для ознакомления:** Читайте `project_context/GUIDE_RUSSIAN.md`.
2.  **Для разработки:** Используйте `project_context/TECHNICAL_KNOWLEDGE_BASE_ENGLISH.md` как техническое задание.
3.  **Для тестов:** Используйте файлы из `ExperOS Files/Sample Cases`.
