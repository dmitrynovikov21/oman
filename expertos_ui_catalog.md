## About ExpertOS

**Tech Stack:**
- Next.js 14 (App Router)
- TypeScript
- Prisma ORM + SQLite
- Tailwind CSS + shadcn/ui
- Python EasyOCR backend

**Key Features:**
- OCR document processing (Arabic/English)
- Omani Labor Law calculator (EOSB, leave, gratuity)
- Full-text search across cases and OCR text
- Real-time dashboard analytics
- Micro-animations and visual polish
