## Technical Implementation

### OCR Pipeline

```
1. PDF → PyMuPDF → PNG images (4x resolution)
2. PNG → OpenCV preprocessing:
   - Grayscale conversion
   - Noise reduction (fastNlMeansDenoising)
   - Contrast enhancement (CLAHE)
   - Sharpening filter
3. Preprocessed PNG → EasyOCR (Arabic + English models)
4. Raw text → Postprocessing (Arabic corrections dictionary)
5. Final text → Save to file
```

### Dependencies

```
Python 3.11
├── PyMuPDF (fitz) - PDF to image conversion
├── EasyOCR - Arabic/English OCR
├── OpenCV - Image preprocessing
└── FastAPI + Uvicorn - OCR API server
```
