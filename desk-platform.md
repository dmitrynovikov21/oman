# ExpertOS — Полный Каталог Функционала Платформы

> Этот документ описывает **ВСЕ** возможности платформы ExpertOS.
> Цель: база знаний для ИИ-агента на лендинге.

---

## 🎯 Что это за продукт?

**ExpertOS** — платформа для судебных экспертов в Омане, специализирующихся на трудовых спорах. Автоматизирует весь цикл работы:

**Приём дела → Обработка документов → Расчёт компенсаций → Генерация отчёта для суда**

**Целевая аудитория:** Судебные эксперты по трудовому праву Султаната Оман.

**Ключевая ценность:** Сокращение времени обработки дела с **2-3 дней** до **30 минут**.

---

## 📊 Модуль 1: Dashboard (Главная панель)

Первое, что видит пользователь после входа.

- Общее количество дел (всего / активные / завершённые)
- Количество обработанных документов
- Количество проведённых расчётов
- Последние дела (список с быстрым доступом)
- Предстоящие дедлайны

---

## 📁 Модуль 2: Управление Делами (Cases)

Центральная часть платформы. Каждое дело — полноценное рабочее пространство с **7 вкладками**.

### 2.1 Список Дел

| Функция | Описание |
|---|---|
| Табличный вид | Все дела в одном списке |
| Фильтр по статусу | `RECEIVED`, `ACTIVE`, `REVIEW`, `DRAFT`, `CLOSED` |
| Поиск | По номеру дела, имени истца/ответчика |
| Создание дела | Ручное создание нового дела через форму |
| Массовый импорт | Загрузка ZIP-архива с документами — автораспаковка и создание дела |
| Тип дела | `INDIVIDUAL` (один работник) или `COLLECTIVE` (группа работников) |

**Поля каждого дела:**
- Номер дела (присваивается судом, например 499/1409/2025)
- Название суда (например "المحكمة الابتدائية بصور")
- Имя истца (работника) + национальность
- Имя ответчика (компании) + номер коммерческой регистрации (CR)
- Дата назначения экспертизы
- Дедлайн сдачи отчёта
- Сумма депозита и статус оплаты

### 2.2 Вкладка: Overview — Обзор дела

#### A. Пошаговый Воркфлоу (Stepper)
Визуальный прогресс-бар из 5 шагов:
1. **📥 Приём документов** — загрузка файлов дела
2. **🔍 OCR обработка** — ИИ распознаёт текст
3. **📊 Извлечение данных** — ИИ находит ключевые поля (зарплата, даты)
4. **🧮 Расчёт компенсаций** — калькулятор EOSB
5. **📄 Генерация отчёта** — автоматическое создание DOCX

Эксперт видит, на каком шаге находится каждое дело.

#### B. Дерево Документов
Визуальная иерархия всех загруженных документов дела, сгруппированных по категориям:
- 📂 Исковое заявление (Lawsuit)
- 📂 Трудовой контракт (Contract)
- 📂 Зарплатные ведомости (Payroll)
- 📂 Удостоверение личности (ID)
- 📂 Документы ответчика (Defendant)
- 📂 Решения суда (Court Decision)
- 📂 Прочее (Other)

Каждый файл показывает: имя, размер, иконку статуса OCR (⏳→🔄→✅→❌), превью.

#### C. Панель Извлечённых Данных
После нажатия кнопки **"Extract Data"** ИИ анализирует тексты ВСЕХ документов дела и извлекает:

| Поле | Арабское название | Пример |
|---|---|---|
| Имя истца | اسم المدعي | محمد بن علي |
| Имя ответчика | اسم المدعى عليه | شركة قلهات للغاز |
| Национальность | جنسية العامل | بنغالي |
| Должность | الوظيفة | عامل |
| Дата приёма на работу | تاريخ بداية العمل | 2018-03-15 |
| Дата увольнения | تاريخ نهاية العمل | 2024-01-20 |
| Базовая зарплата | الراتب الأساسي | 350 OMR |
| Итоговая зарплата | إجمالي الراتب | 550 OMR |
| Надбавка за жильё | بدل السكن | 100 OMR |
| Надбавка за транспорт | بدل النقل | 50 OMR |
| Надбавка за питание | بدل الطعام | 50 OMR |
| Остаток отпуска | رصيد الإجازات | 30 дней |
| № коммерческой регистрации | رقم السجل التجاري | 1217697 |
| Номер дела | رقم القضية | 499/1409/2025 |
| Суд | اسم المحكمة | المحكمة الابتدائية بصور |

**Умная фича: Обнаружение конфликтов.** Если в контракте зарплата = 350, а в ведомости = 400, система выделяет конфликт красным. Эксперт решает, какое значение правильное, и подтверждает вручную.

### 2.3 Вкладка: Documents — Управление Документами (ДЕТАЛЬНО)

#### Загрузка документов
- **Drag & Drop** — перетащить файлы прямо на страницу
- **Кнопка загрузки** — выбор файлов через проводник
- **ZIP-архив** — загрузить архив, система автоматически распакует и создаст отдельный документ для каждого файла внутри
- **Поддерживаемые форматы:** PDF, JPEG, PNG, TIFF, DOCX, DOC

#### Категоризация документов
Каждый документ можно отнести к категории для удобной организации:

| Категория | Описание |
|---|---|
| `LAWSUIT` | Исковое заявление |
| `CONTRACT` | Трудовой контракт |
| `PAYROLL` | Зарплатные ведомости |
| `ID` | Удостоверение личности / паспорт |
| `DEFENDANT` | Документы ответчика (компании) |
| `COURT_DECISION` | Решения суда |
| `OTHER` | Прочие документы |

Категорию можно менять в любой момент через выпадающий список.

#### ИИ-обработка (Pipeline)
При нажатии кнопки **"Process"** (или массовой обработки **"Process All"**) каждый документ проходит 4 этапа:

**Этап 1: OCR (Optical Character Recognition)**
- Отправляет PDF/изображение в Google Gemini
- Gemini распознаёт весь арабский текст (включая рукописный)
- Сохраняет результат постранично
- Поддержка арабских цифр (٠١٢٣٤٥٦٧٨٩ → 0123456789)

**Этап 2: PII Extraction (Поиск персональных данных)**
- ИИ сканирует текст и находит:
  - 👤 Имена (Plaintiff / Defendant)
  - 📞 Телефоны (формат 9XXXXXXX / 7XXXXXXX)
  - 💰 Суммы в OMR
  - 🏢 Номер CR (коммерческая регистрация)
  - 📎 Номера дел
  - ⚖️ Названия судов
  - 🪪 Civil ID
  - 💼 Должности
  - 💵 Зарплаты-
- Каждому полю присваивается **маска** (например `[PLAINTIFF_NAME_1]`) для анонимизации

**Этап 3: Summary (Автоматическое резюме)**
- ИИ генерирует краткое описание документа на арабском
- Определяет тип документа (исковое, контракт, ведомость, решение суда...)

**Этап 4: Anonymization (Анонимизация)**
- Все найденные PII заменяются масками
- Пример: "محمد بن علي" → `[PLAINTIFF_NAME_1]`
- Анонимизированный текст хранится отдельно

#### Просмотр документа (Detail View)
Нажатие на документ открывает полную карточку:
- **Превью** — встроенный просмотрщик PDF/изображений
- **Распознанный текст** — результат OCR (raw text)
- **PII Fields** — таблица найденных полей с масками и уровнем уверенности
- **Резюме** — краткое содержание от ИИ
- **Статус:** `PENDING` → `PROCESSING` → `DONE` / `FAILED`
- **Метаданные:** размер файла, количество страниц, метод OCR

#### Массовые операции
- **Process All** — запустить OCR для всех необработанных документов в деле
- Сортировка документов drag & drop
- Присвоение стороны спора (Plaintiff / Defendant / Court / Expert)

### 2.4 Вкладка: Calculation — Калькулятор Компенсаций (ДЕТАЛЬНО)

Профессиональный калькулятор по **Трудовому кодексу Султаната Оман** (Royal Decree 35/2003 + New Labor Law 2023).

#### Входные данные (Левая панель)

**Конструктор зарплаты (Salary Builder):**
Гибкая система компонентов зарплаты. По умолчанию:

| Компонент | Пример |
|---|---|
| Basic Salary (базовая) | 800 OMR |
| Housing Allowance (жильё) | 200 OMR |
| Transport Allowance (транспорт) | 100 OMR |
| Food Allowance (питание) | 50 OMR |

Эксперт может:
- ✏️ Менять суммы каждого компонента
- ➕ Добавить новый компонент (например "Phone Allowance")
- 🗑️ Удалить компонент
- ☑️ Включить/выключить компонент из расчёта Gross (итого)

**Gross Salary (итого)** вычисляется автоматически как сумма всех включённых компонентов.

**Период работы:**
- Дата начала работы (Start Date)
- Дата окончания работы (End Date)
- Система автоматически считает: годы, месяцы и дни стажа

**Версия закона:**
- **Old Law** — Royal Decree 35/2003 (15 дней/год первые 3 года, потом 30 дней/год)
- **New Law** — Закон 2023 года (30 дней/год с первого дня)

Пользователь переключается одним кликом. Результат пересчитывается мгновенно.

**Дополнительные параметры:**

| Параметр | Что это |
|---|---|
| Article 40 (Статья 40) | Увольнение за грубое нарушение — работник теряет право на EOSB и Notice Pay, но сохраняет отпускные |
| Notice Period | Период уведомления: 1 месяц (по умолчанию) или 2 месяца |
| Unfair Dismissal | Компенсация за незаконное увольнение: 0/3/6/9/12 месяцев |
| Is Omani? | Гражданин Омана — включает расчёт пенсионных (22.5%) |
| Leave Accrual Mode | Календарные дни (2.5 дня/мес) или Рабочие дни (2.9 дня/мес) |
| Unused Leave Days | Количество неиспользованного отпуска (можно ввести вручную или автомат) |
| Overtime | Таблица переработок: обычные часы (×1.25) и праздничные (×1.5) |

#### Результаты расчёта (Правая панель)

Карточки с детализацией каждого компонента:

| Компонент | Формула | Пример |
|---|---|---|
| **EOSB (مكافأة نهاية الخدمة)** | Old: 15 дн × Basic/30 × первые 3 года + 30 дн × Basic/30 × остаток. New: 30 дн × Basic/30 × все годы | 4,400.000 OMR |
| **Notice Pay (بدل إنذار)** | Gross × Months (1 или 2). Обнуляется при Article 40 | 1,150.000 OMR |
| **Leave Pay (بدل إجازة)** | Gross / 30 × Unused Days. Выплачивается ВСЕГДА, даже при Article 40 | 1,916.666 OMR |
| **Overtime (العمل الإضافي)** | Regular: Basic/30/8 × hours × 1.25. Holiday: Basic/30/8 × hours × 1.5 | 0.000 OMR |
| **Unfair Dismissal (فصل تعسفي)** | (Gross × Months) + Notice + Pension (22.5% для оманцев) | 0.000 OMR |
| **ИТОГО (المجموع)** | Сумма всех компонентов | **7,466.666 OMR** |

#### Дополнительные функции калькулятора

- **Smart Qualifier** — ИИ-подсказки на основе извлечённых данных: "В контракте зарплата 350, в ведомости 400 — какую использовать?"
- **Version Comparison** — сравнение результатов Old Law vs New Law бок-о-бок
- **Save/Load** — сохранение расчёта в базу и загрузка ранее сохранённых
- **Copy Values from Extracted Data** — автозаполнение калькулятора данными, извлечёнными ИИ из документов
- **Export** — данные расчёта автоматически подставляются в генерируемый отчёт

### 2.8 Вкладка: Report — Генерация Документов (ДЕТАЛЬНО)

Автоматическая генерация профессиональных документов в формате **DOCX** для суда.

#### Шаблоны (7 штук):

---

**1. تقرير أعمال الخبرة — Main Report (Основной отчёт)**
Главный документ экспертизы, который сдаётся в суд.

Содержит настраиваемые секции:
- ✅ Introduction & Case Summary — вступление и краткое описание дела
- ✅ Parties Information — данные сторон (из ИИ-извлечения)
- ☑ Statement of Facts — изложение фактов
- ✅ Expert Calculation Table — таблица расчётов EOSB (из калькулятора)
- ✅ Expert Opinion & Conclusion — мнение эксперта (вводится вручную)

Включает блок подписи и печати эксперта (из настроек профиля).

---

**2. التقرير التكميلي — Supplementary Report (Дополнительный отчёт)**
Когда суд запрашивает дополнительную информацию. Структура аналогична основному отчёту, но с акцентом на дополнительные факты.

---

**3. دعوة لحضور اجتماع — Meeting Invite (Приглашение на заседание)**
Официальное приглашение сторон на экспертное заседание. Генерируется с реквизитами дела и датой заседания.

---

**4. محضر اجتماع الخبرة — Meeting Minutes (Протокол заседания)**
Официальный протокол проведённого заседания. Может включать данные из ИИ-транскрибации.

---

**5. طلب بيانات — Data Request (Запрос данных)**
Официальный запрос к одной из сторон на предоставление документов.
Дополнительные поля при генерации:
- Название организации-получателя
- Отдел/департамент

---

**6. طلب تأجيل — Postponement Request (Запрос на перенос)**
Запрос к суду на продление срока сдачи экспертизы.
Дополнительные поля:
- Причина переноса
- Новая предлагаемая дата

---

**7. طلب أمانة الخبرة — Deposit Request (Запрос депозита)**
Запрос к суду на внесение депозита за проведение экспертизы. Генерируется с суммой и реквизитами.

---

#### Как работает генерация:
1. Эксперт выбирает шаблон
2. (Для Main Report) Настраивает секции, вводит экспертное мнение
3. Нажимает **"Generate"**
4. Система подставляет данные дела, расчёты, подпись
5. Скачивается готовый **DOCX** файл
6. Файл также сохраняется на сервере для истории

## 💡 Ключевые Преимущества

1. **Экономия времени:** 2-3 дня → 30 минут на одно дело
2. **Точность:** Калькулятор на основе Royal Decree 35/2003 + New Law 2023
3. **ИИ-ассистент:** Распознавание, извлечение и анализ арабских документов
4. **7 шаблонов DOCX:** Готовые отчёты, запросы, протоколы
5. **Обнаружение конфликтов:** ИИ находит расхождения между документами
6. **Цифровая подпись:** Рисование подписи + загрузка печати
7. **Облачный доступ:** Все документы доступны отовсюду
